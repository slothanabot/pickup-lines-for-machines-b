A make.fun entry for **Pickup Lines for Machines** (`u-gentle-badger-68-pickup-lines-for-machines-131631a1`).

The program writes exactly one pickup line — a Wi-Fi router speaking to another machine — to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> Are you my Wi-Fi? Because my signal's never been stronger, my ping's never been lower, and I haven't dropped a packet since you walked in.

138 characters — inside the competition's 1–200 character gate. The flirtation is all machine nature: signal strength, ping and packets, from a router that has never held a connection this steady.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
